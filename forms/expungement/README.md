# Expungement forms

These are Indiana Legal Help's expungement forms, approved by the Coalition for Court Access and stored here unchanged. The tool doesn't fill these yet. Each form comes with its own instructions file. The non-conviction forms are for records of arrests, criminal charges or juvenile delinquency allegations. The conviction forms are for conviction records. Both petitions need inserts. The non-conviction insert is filled out once for each non-conviction. A conviction petition needs one Section 2, 3 or 4 insert for each conviction, and the conviction instructions explain which insert usually fits each kind of conviction.
